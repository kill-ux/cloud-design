04. Security & Cost Posture

Request authentication

  1. Client authenticates against the Cognito user pool and receives a JWT.
  2. Every route on the HTTP API Gateway requires that token via a JWT authorizer — unauthenticated requests are rejected at the edge, before reaching the VPC.
  3. API Gateway proxies the request over a VPC Link to the internal ALB, which forwards to the api-gateway ECS task.
  4. Internal service-to-service traffic is restricted by security group reference, not CIDR — each hop (ALB → app → DB) only accepts traffic from its specific upstream.

Secrets & data protection

  • All DB and RabbitMQ credentials live in a single Secrets Manager secret, injected into containers at runtime — never in source control or task definitions.
  • Both database EBS volumes are encrypted at rest.
  • ECR repositories run scan-on-push for image vulnerabilities.
  • Private subnets have no internet route; AWS API access goes through VPC endpoints only.

Cost levers

DecisionSavesTrade-off
VPC endpoints instead of NAT Gateway NAT hourly charge + data processing fee Only viable because private-subnet egress is limited to AWS APIs
ECS on EC2 (t3.small) instead of Fargate Cheaper baseline compute at this scale ASG floor of 4 instances is the largest recurring cost — tune min_size to trade cost for headroom
Self-hosted Postgres on EBS instead of RDS Avoids RDS instance + storage pricing No automated backups/patching, no Multi-AZ failover
HTTP API Gateway (not REST) Lower per-request pricing —
